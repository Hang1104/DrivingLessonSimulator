#  Driving Lesson Simulator

A driving simulation game built for Malaysian learners preparing for their JPJ driving test.

## About
This is my Final Year Project at UTAR. The game simulates real driving scenarios 
commonly encountered in the Malaysian driving test, helping learners practice 
before their actual test.

## Features
- Realistic Malaysian driving test scenarios
- Interactive driving mechanics
- Built for learner drivers preparing for JPJ test

## Tech Stack
- Unity
- C#
