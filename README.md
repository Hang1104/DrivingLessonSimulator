# Learn to Drive – Gamification with Unity

A gamification app to help Malaysians prepare for their JPJ driving test.

## About
Final Year Project at UTAR. Built a Unity-based driving simulator that 
provides a safe, cost-effective environment to practice Malaysian driving 
test scenarios anytime, anywhere.

## Features
- 4 driving lessons: Selekoh S Road, Parallel Parking, 3-Point Turn, Slope Test
- KPP Test practice with multiple topics
- User login, registration & forget password (Firebase)
- Score tracking and lesson summary
- Step-by-step in-game instructions

## Tech Stack
Unity · C# · Firebase Console · Android Studio

## What I Learned
- Implementing 3D driving physics and collision detection in Unity
- Integrating Firebase for user authentication and score tracking
- Designing step-by-step in-game instruction systems
- Building and deploying an Android app via Google Play Console
